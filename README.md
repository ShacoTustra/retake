# Retake — черновой монтаж уроков по транскрипту

Находит в сырой записи неудачные дубли, оговорки, разговоры не по уроку и длинные паузы,
показывает их в редакторе с дорожками, а после проверки собирает готовое видео
(для iMovie) или таймлайн FCPXML (для Final Cut Pro / DaVinci Resolve).

```
видео ─► распознавание ─► поиск правил ─► [второе мнение LLM] ─► проверка человеком ─► сборка
         (Whisper, слова   (дубли, паузы,   (необязательно: любой    (страница в        (ffmpeg:
          с таймкодами)     маркеры «ой»)    OpenAI-совместимый API)  браузере)          mp4 / fcpxml)
```

## Приложение для Mac

Для тестеров — [BETA.md](BETA.md): установка из `.dmg`, первый запуск, обратная связь.

**Сборка.** `.dmg` собирает GitHub Actions (`.github/workflows/build-mac.yml`, раннер macOS 15 на Apple Silicon):
запуск вручную (Actions → Build macOS app → Run workflow) — артефакт сборки, тег `v*` — pre-release
со ссылкой для тестеров. Сборка с самотестом занимает ~15–20 минут.

```bash
git tag v0.1.0-beta.2 && git push origin main --tags     # версия — в retake/runtime.py
```

То же локально на любом Mac с Apple Silicon: `packaging/build_mac.sh` (нужен Python 3.12+).
Скрипт ставит зависимости, скачивает статический ffmpeg (контрольные суммы зафиксированы), собирает
`Retake.app` через PyInstaller, подписывает ad-hoc, **запускает самотест собранного приложения**
(распознавание маленькой моделью, поиск, сборка ролика, локальный сервер) и упаковывает `dist/Retake-<версия>.dmg`.
В CI приложение затем ставится из этого `.dmg` и проверяется как у человека: настоящие клики, системное окно выбора
файла, перетаскивание из Finder, клавиши, экспорт, перезапуск (`tests/mac_app_check.py`).
Для подписи Developer ID и нотаризации: `CODESIGN_IDENTITY=… NOTARY_PROFILE=… packaging/build_mac.sh`.

Проверить установленное приложение на чужом Mac: `/Applications/Retake.app/Contents/MacOS/Retake --selftest`.

Устройство: `retake/desktop.py` — нативное окно (pywebview, WKWebView) над локальным сервером `retake/app.py`;
модель распознавания (`mlx-community/whisper-large-v3-turbo`, 1.6 ГБ) скачивается при первом использовании
в `~/Library/Application Support/Retake/models` с докачкой и проверкой SHA-256; журнал —
`~/Library/Application Support/Retake/logs/retake.log`.

## Запуск из репозитория на Mac

Нужен Mac на Apple Silicon и Python 3.12 (или [uv](https://docs.astral.sh/uv/): он поставит Python сам).

```bash
git clone https://github.com/ShacoTustra/retake.git && cd retake
./setup_mac.sh        # окружение, ffmpeg, проверка всего пути на коротком ролике (≈ 80 МБ маленькой модели)
./Retake.command      # окно приложения; ./Retake.command --browser — то же в браузере
```

`Retake.command` можно запускать двойным кликом. Основная модель распознавания (1.6 ГБ) скачается при первом уроке.
Если macOS спросит доступ к папке с видео, разрешите его Терминалу. Обновиться: `git pull`.

## Разработка на Linux/WSL

```bash
uv venv .venv -p 3.12
uv pip install -p .venv/bin/python faster-whisper rapidfuzz numpy     # и ffmpeg из пакетов системы
.venv/bin/python retake/app.py                                        # http://127.0.0.1:8765
```

## Приложение

1. **Добавить запись урока…** — выбрать видео (или перетащить в окно). Оно не копируется и не меняется.
2. Карточка урока показывает прогресс: распознавание → поиск → проверка LLM (если включена).
3. **Открыть** — редактор: дорожки, видео, текст и подсказки. Решения сохраняются сами.
4. **Экспорт** — готовый ролик `<имя> (монтаж).mp4` рядом с исходником. **FCPXML** — таймлайн.

Данные приложения (расшифровки, решения, настройки, журнал): `~/Library/Application Support/Retake`
на Mac, `~/.local/share/retake` на Linux. Сервер слушает только `127.0.0.1`, запросы защищены токеном.

## Второе мнение LLM (необязательно)

Модель читает расшифровку, высказывается по каждому найденному дублю (вырезать / оставить)
и ищет то, что правила не видят: оговорки без маркера, «язык прикусила», разговор с питомцем,
«не знаю, слышно ли будет». В облако уходит только текст. Точные границы вырезок модели не доверяются:
она указывает номера фраз, а место реза ищется в тишине по громкости, как и для остальных правок.

Настраивается в приложении (**Настройки**) или переменными окружения / файлом `.env` в папке проекта:

```bash
LLM_BASE_URL=https://api.proxyapi.ru/v1        # любой OpenAI-совместимый: OpenAI, OpenRouter,
LLM_MODEL=anthropic/claude-haiku-5-5           #   Ollama (http://localhost:11434/v1), LM Studio (…:1234/v1)
LLM_API_KEY=sk-...                             # или API_KEY / OPENAI_API_KEY
```

На первом уроке (50 мин) `anthropic/claude-haiku-5-5` через proxyapi: ~21 тыс. токенов на входе,
~10 тыс. на выходе (в основном «размышления»), меньше минуты, около цента за урок по ценам Anthropic.
«Размышления модели: мало» (`reasoning_effort=low`) обязательно для Haiku 5.5: на значении по умолчанию
модель тратила весь лимит ответа на размышления и не успевала ответить.

В редакторе у каждой подсказки видно мнение модели; фильтр **«✦ Спорные и новые»** оставляет
только места, где модель не согласна с правилами, и её собственные находки. Новые находки
отмечаются к вырезке, только если модель уверена (настраивается).

## Редактор

Экран как в обычной монтажной программе: текст урока, видео и подсказки сверху, дорожки снизу.

- **Дорожки**: подсказки, текст, видео (кадры), звук (волна). Сверху полоса всего урока.
- **Исходник / Результат** (`R`): вся запись с затенённым вырезанным или готовое видео со стыками.
- **Инструмент выбирается сам**: линейка двигает курсор, край правки сдвигает границу, всё остальное выделяет кусок. Границы прилипают к паузам между словами (`⌥` — свободно, `N` — выключить).
- **Текст**: выделили слова — выделился кусок видео, `⌫` его вырезает.
- **Слушать стык** (`P`): два `<video>`, второй заранее стоит за вырезкой, поэтому переход занимает миллисекунды и слышен сам стык, а не пауза на перемотку.
- **Отмена** всего (`⌘Z`), решения сохраняются сами. Все клавиши: `?`.

Код: `retake/ui/js/` (`model.js` — правки и время, без DOM; `player.js`; `timeline.js`; `panels.js`; `editor.js`). Без сборки и зависимостей.

Тесты: `node --test tests/*.mjs` и `.venv/bin/python -m unittest discover tests`.

## Командная строка

```bash
V=~/Movies/lesson.mp4
.venv/bin/python retake/transcribe.py "$V" -o work/tr.json          # можно кусок: --start 0 --duration 900
.venv/bin/python retake/detect.py work/tr.json -o work/edits.json
.venv/bin/python retake/llm.py work/edits.json -o work/edits.json   # необязательно; --dry-run покажет запрос
.venv/bin/python retake/make_review.py work/edits.json              # страница-файл рядом с видео
.venv/bin/python retake/render.py ~/Downloads/lesson.edits.json --mp4 lesson_cut.mp4 [--fcpxml lesson.fcpxml]
.venv/bin/python retake/check_splices.py edits.json                 # QA: ни один стык не попал в речь
```

## Как ищутся правки

| Тип | Как находим | По умолчанию |
|---|---|---|
| **Дубль** с маркером | после фразы идёт «ой», «блин», «тьфу», короткое «ещё раз.» → вырезаем неудачную попытку вместе с маркером | вырезать |
| **Дубль** без маркера | фраза начинается так же, как одна из следующих в пределах 25 с («последний дубль побеждает») | вырезать |
| Точный повтор | та же фраза целиком, без маркера (учитель читает пример дважды) | **оставить** |
| Короткая перефразировка | «Мне нравится блюдо. Мне нравится еда.» — часто вариант перевода | **оставить** |
| **Пауза** | промежуток между словами ≥ 1.2 с, режется только реальная тишина (по громкости), остаётся 0.8 с | вырезать |
| Запинка | «это это» — в уроках почти всегда намеренно («наника-наника», «знаем, знаем») | оставить |
| **Не по уроку** (LLM) | служебные реплики, разговор с кем-то рядом | вырезать, если модель уверена |
| Мнение LLM по дублю | вердикт «вырезать / оставить» с причиной; при уверенности high/medium заменяет решение правила | — |

Границы вырезок ставятся в реальную тишину между словами: таймкоды Whisper ошибаются до 0.5 с.

Ловушки, найденные на реальной записи (урок японского на русском):
- «ещё раз» — и маркер ошибки, и обычная фраза учителя («прочитаем ещё раз») → маркер только как отдельная короткая фраза;
- «извините» — перевод すみません, а не извинение;
- «м», «э» в кавычках — звуки, о которых идёт речь, а не мычание;
- японская речь при `language=ru` записывается кириллицей («ТАБЕМАС») — для поиска дублей не мешает, для субтитров нужен другой подход;
- распознавание искажает маркеры («показатель совместного блинка») — такие места находит только LLM.

## Горячие клавиши

Полный список в самом редакторе: кнопка «Клавиши» или `?`. Клавиши работают и в русской раскладке.

| Клавиша | Действие |
|---|---|
| `Пробел`, `J` `K` `L` | пуск и пауза; назад, стоп, вперёд (повторное нажатие быстрее) |
| `Tab`, `⇧Tab` | следующая и предыдущая подсказка, сразу включает это место |
| `X` | вырезать или оставить |
| `Enter` | согласиться с подсказкой и перейти дальше |
| `P`, `⇧P` | послушать стык; послушать, что вырезаем |
| `I`, `O`, `⌫`, `⇧⌫` | выделить кусок, вырезать его, вернуть вырезанное в нём |
| `S` или `⌘B` | разрезать в позиции курсора |
| `←` `→`, `⇧←` `⇧→`, `⌥←` `⌥→` | на кадр, на секунду, на слово |
| `↑` `↓` | к соседнему стыку |
| `R` | исходник или результат |
| `⌘Z`, `⇧⌘Z` | отменить, повторить |
